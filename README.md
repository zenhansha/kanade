# KANADE 奏 — iPad と PC で使える作譜アプリ

Finale からの乗り換え用の楽譜作成アプリ。iPad Pro 12.9（第4世代）を主なターゲットにした **Web アプリ（PWA）** で、
タッチ・Apple Pencil・キーボード・MIDI キーボードで入力できる。PC のブラウザでも同じものが動く。

いまは **Phase 2（記号・歌詞・反復・パート譜）** まで完成した段階。

---

## 起動のしかた

### PC で試す
`start_kanade.bat` をダブルクリック（または `python serve.py`）→ ブラウザで http://localhost:8080 が開く。
MIDI キーボードを使うなら **Chrome か Edge** で開く。

### iPad で使う（3つの方法）

| 方法 | 手軽さ | オフライン | MIDI | 備考 |
|---|---|---|---|---|
| ① 同じ Wi-Fi で PC から配信 | ◎ | ✕ | ✕ | `python serve.py` で表示される `http://192.168.x.x:8080` を iPad の Safari で開く。PC を起動している間だけ使える |
| ② GitHub Pages に置く（おすすめ） | ○ | ◎ | ✕ | 無料の https サーバー。Safari で開いて「共有 → ホーム画面に追加」すると普通のアプリのように全画面・オフラインで使える |
| ③ ②＋ Web MIDI 対応ブラウザ | ○ | ◎ | ◎ | iPad の Safari は MIDI 非対応。App Store の「Web MIDI Browser」などで②の URL を開くと USB / Bluetooth の MIDI キーボードが使える |

> **なぜ https が必要？** オフラインで動かす仕組み（Service Worker）は、安全のため https（か localhost）でしか動かない決まりになっているため。①は http なので、オフライン保存とホーム画面アプリ化はできない（普通に使うのは問題なし）。

楽譜データは **その端末の中（ブラウザの IndexedDB）** に自動保存される。端末をまたぐときは MusicXML で書き出す。

### 公開版（GitHub Pages）を iPad にインストールする
公開先：**https://zenhansha.github.io/kanade/**

1. iPad の **Safari** で上の URL を開く
2. 共有ボタン（□↑）→ **「ホーム画面に追加」**
3. ホーム画面の KANADE アイコンから起動（全画面・オフラインで動く）

更新したときは、ネットにつながった状態でアプリを一度開き直すと新しい版になる。
ホーム画面のアプリと Safari のタブは保存場所が別なので、楽譜はどちらか一方で作り続けるのがおすすめ。

### PC（Windows / Mac）で使う
同じ URL を **Edge か Chrome** で開くだけ。アドレスバー右端のインストールアイコン（またはアプリの「ファイル → アプリとしてインストール」）で、
スタートメニューから起動できる専用ウィンドウのアプリになる（オフラインでも動く）。

| PC でできること | やり方 |
|---|---|
| ファイルに保存 | `Ctrl+S` で **.kanade ファイル**に保存。2回目からは同じファイルに上書き（タイトルの ● = 未保存の変更あり）。`Ctrl+Shift+S` で名前を付けて保存 |
| ファイルを開く | `Ctrl+O` →「PC のファイルを開く」、またはウィンドウに**ドラッグ＆ドロップ**。インストール後は .kanade / .musicxml / .mxl を「プログラムから開く」で KANADE を選べる |
| マウス操作 | ドラッグで範囲選択、**右クリック**でメニュー、**ダブルクリック**でそこから入力、音符に乗せると色が付く |
| 大きな画面 | 「画面に合わせる」（`Ctrl+0` / 倍率表示をクリック）で、100% 以上を保てる幅ならページを横に並べる。ウィンドウの大きさを変えると合わせ直す |
| MIDI キーボード | Edge / Chrome ならそのまま使える（USB でつなぐだけ） |

**.kanade** は KANADE の情報（改段・ページ設定など）を全部残す保存形式。iPad では「ファイル → .kanade ファイルに書き出す」で
「ファイル」アプリや iCloud Drive に置けば、PC で開いて続きを書ける（逆も同じ）。ほかのソフトへは MusicXML で渡す。
新規作成は `Alt+N`（ブラウザでは `Ctrl+N` が「新しいウィンドウ」に取られるため）。

## 使い方（Finale ユーザー向け）

**モードは2つだけ。** Finale の「ツールを選んでからクリック」はやめて、
- **入力モード**（ピンクのカーソル）… 音を入れる。`N` キーかパレット左の「入力」
- **選択モード**（青）… 選んで直す。`Esc` か「選択」

### 音を入れる
- **タップ / Apple Pencil**：五線の上をタップすると、その高さ・その位置に今の音価で入る。ペン（やマウス）なら押したまま動かすとゴースト音符が出るので、離す前に高さを確認できる。**指でなぞるとスクロール、ペンは入力** と分けている。
- **キーボード**：数字で音価（Finale の Speedy Entry と同じ：`5`=4分, `4`=8分, `6`=2分, `7`=全）→ `A`〜`G` で音名。前の音に一番近いオクターブに入る。`Shift`+音名で和音。
- **MIDI キーボード / 画面鍵盤**：弾いた音がカーソル位置に入って進む（ステップ入力）。**押さえたまま次の鍵盤**を弾くと和音。左手で音価、右手で鍵盤、という Finale と同じ流れ。
- 小節をはみ出す長さは自動で分割してタイでつなぐ。最後の小節の先まで入力すると小節が自動で増える。

### 直す
- 音符をタップで選択 → `↑↓`（半音）、`Alt+↑↓`（全音階）、`Ctrl+↑↓`（オクターブ）、ペンで上下ドラッグ。
- パレットの音価ボタンで長さを変更、`♯ ♮ ♭` で臨時記号、削除で休符に。
- 小節の空いている所をタップで小節選択、続けて別の小節をタップで範囲選択 → コピー・貼り付け・移調・削除。

ショートカット一覧と Finale との対応表はアプリ右上の「?」にある。

### Finale から引っ越す
Finale で **ファイル → 書き出し → MusicXML** → KANADE の **ファイル → MusicXML を読み込む**。
`.musicxml` / `.xml` / `.mxl`（圧縮）に対応。B♭クラリネットなどの移調楽器は実音に直して読み込む。
Finale が動くうちに、手持ちのデータを全部 MusicXML で書き出しておくのがおすすめ。

## Phase 2 でできること

パレット左の **「記号」タブ**に切り替えると使える。音符を選んで（Shift+クリックで範囲）ボタンかキーを押す。

| 機能 | やり方 | Finale でいうと |
|---|---|---|
| アーティキュレーション（スタッカート・テヌート・アクセント・マルカート・フェルマータ・トリル・モルデント・ターン・ボウイング・ブレス） | Shift+S / N / V / O / U、「ほか」 | アーティキュレーションツール |
| 強弱記号（ppp〜fff・fp・sf・sfz・sfp・rfz）・文字の表情記号（dolce・rit.・pizz.…自由入力も） | パレット / X キー | 発想記号ツール |
| スラー・クレッシェンド/デクレッシェンド（松葉）・8va/8vb/15ma・ペダル・トリルの波線 | S / < / >、「ほか」。入力モードで押すと入れながら伸びる | スマートシェイプ |
| 歌詞（1番〜8番、ハイフン、日本語入力のままでも可） | L → 打ってスペースで次の音符 | 歌詞ツール（Type Into Score） |
| コードネーム（C、F#m7b5、Bbmaj7/D …） | K → 打ってスペースで次の音符 | コードツール |
| 装飾音符（斜線付き・16分の連桁つきなど） | ; で装飾音符モード | Speedy の ; |
| 反復記号（|: :|・回数・1番2番カッコ・セーニョ・コーダ・Fine・D.C./D.S.）。**再生もその順番** | 「反復」ボタン / 小節メニュー | 反復記号ツール |
| パート譜（リンクパート：スコアと同じデータ。続く休みは複数小節休符にまとまる） | 上のバーの「表示」 | リンクパート |
| 移調楽器を記譜音で表示（B♭クラ・E♭アルトサックス・F管ホルン…） | 「表示」→ 記譜音で表示 | 「実音で表示」のチェックを外す |
| 再生への反映：強弱・松葉・アクセント・スタッカート・フェルマータ・8va・ペダル・装飾音・トリル | 自動 | Human Playback の一部 |

付けた記号はクリックで選べる（←→ で線の終わり、Shift+←→ で始まり、Delete で削除、ダブルクリックで編集）。
MusicXML の読み書きにもすべて対応しているので、Finale で付けた記号もそのまま引っ越せる。

## しくみ（勉強用）

ビルド不要。ブラウザの ES モジュールをそのまま読み込んでいる。

```
index.html / css/app.css     画面
js/core/music.js             音価（ティック）と音高（綴り）の基本計算
js/core/score.js             楽譜データの形、楽器・テンプレート
js/core/edit.js              編集操作（上書き入力・タイ分割・連符・小節操作）
js/core/marks.js             記号（アーティキュレーション・強弱・線・歌詞・コード・装飾音・反復の演奏順・移調表示）
js/core/history.js           元に戻す / やり直し
js/engrave/layout.js         浄書エンジン：データ → ページごとの SVG
js/ui/*.js                   楽譜ビュー（タップ判定・ズーム）、パレット、画面鍵盤、ダイアログ、ショートカット
js/audio/*.js                音源（サンプル＋内蔵シンセ）と再生スケジューラ
js/io/*.js                   MusicXML、.mxl 解凍、.kanade 形式、端末内保存・PC のファイル保存
js/midi.js                   Web MIDI 入力
sw.js / manifest.webmanifest オフライン対応・ホーム画面アプリ化
tests/run.js                 テスト（node tests/run.js）
```

### ポイント1：長さは整数の「ティック」で持つ
4分音符 = 6720 ティック。6720 = 2⁶×3×5×7 なので、3連符・5連符・7連符を 128分音符まで割っても整数のまま。
小数（1/3 = 0.333…）で持つと誤差が積もって「小節がぴったり埋まらない」バグの元になる。

### ポイント2：音高は MIDI 番号ではなく「綴り」で持つ
C♯ と D♭ は同じ鍵盤でも楽譜では別物。だから `{ step: 'C', alter: 1, octave: 4 }` のように持つ（MusicXML と同じ）。
MIDI キーボードから来た番号は、その小節の調号を見て ♯系 / ♭系 を選んで綴る（ヘ長調なら B♭、ニ長調なら F♯）。

### ポイント3：入力は「上書き」
位置 t に長さ d の音を書くと、そこにあったものは消え、半端に残った部分は休符で埋め直される。
声部 1 は常に小節をぴったり埋めた状態を保つので、データが壊れにくい（MuseScore・Dorico と同じ考え方）。

### ポイント4：浄書は「タイミングをそろえて」から「伸ばす」
1. 全パートの「音が始まるタイミング」を集めて、縦にそろう列を作る
2. 列の間隔は音の長さの 0.6 乗に比例（2倍長い音でも間隔は約 1.5 倍。これが読みやすい楽譜のコツ）
3. 臨時記号や付点がぶつからない最小幅を確保
4. 段に詰めて、余った幅を全体に配って右端をそろえる
5. 上下にはみ出す音符を測って譜表の間隔を決め、ページに割り付ける

記号は Dorico 用に作られた無料フォント **Bravura**（SMuFL 規格）。フォント内の「符尾を付ける位置」などの
メタデータを `tools/build_smufl.mjs` で抜き出して `js/smufl.js` にしている。
